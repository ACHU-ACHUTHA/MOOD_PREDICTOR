# 🧠 Mood Predictor

A multilingual AI-based Mood Predictor that analyzes user messages and predicts the emotional tone or mood behind the text.

## 🚀 Live Demo

[🌐 View Live Project] https://moodpredictor1319.streamlit.app/


## 📌 About the Project

Mood Predictor is an AI-powered application designed to understand the emotional context of user messages.

The system accepts text input from the user, processes the message, and predicts the corresponding mood. It is designed to support multiple languages, making it useful for users from different linguistic backgrounds.

## ✨ Features

- 🌍 Multilingual mood prediction
- 🧠 AI-based text analysis
- 💬 User-friendly interface
- 📊 Mood classification from text
- ⚡ Fast prediction
- 🔤 Supports different languages

## 🛠️ Technologies Used

- Python
- Machine Learning / NLP
- HTML
- CSS
- JavaScript
- Flask / FastAPI
- Natural Language Processing

## 🔄 How It Works

1. User enters a message.
2. The text is processed and cleaned.
3. The system analyzes the text using NLP techniques.
4. The trained model predicts the user's mood.
5. The predicted mood is displayed to the user.
